# Comidas-Tipicas-Brasil

## 📌 Sobre o projeto

O Comidas tipicas brasil é um projeto desenvolvido como atividade acadêmica, com o objetivo de praticar conhecimentos de desenvolvimento web e criação de páginas utilizando HTML, CSS e Bootstrap.

O projeto apresenta uma estrutura de navegação e organização de conteúdo em uma página web.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap

## ⚙️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo index.html.
4. Abra o arquivo em um navegador.
